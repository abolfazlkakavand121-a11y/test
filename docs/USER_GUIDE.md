# راهنمای نصب و استفاده از اسکنر کلادفرانت (CloudFront Scanner)

## ۱. نصب فایل APK (Sideload)
1. فایل امضاشده‌ی `CloudFrontScanner-release.apk` (یا در صورت استفاده از نسخه آزمایشی، APK امضاشده خروجی) را روی گوشی اندرویدی خود (اندروید ۷.۰ / API 24 به بالا، سازگار با ARM64 و Universal) کپی کنید.
2. فایل را باز کرده و در صورت درخواست سیستم، گزینه **Install unknown apps** را برای فایل‌منیجر فعال کنید.
3. پس از نصب، برنامه بدون نیاز به Termux، Root یا ساخت حساب کاربری اجرا می‌شود.

### نگهداری کلید امضای Release برای نسخه‌های بعدی
- هرگز کلید امضای Release (`.jks` / `.keystore`) و رمزهای آن (`STORE_PASSWORD` / `KEY_PASSWORD`) را داخل مخزن عمومی یا سورس کد ذخیره نکنید.
- برای آپدیت‌های بعدی برنامه بدون نیاز به حذف نسخه قبلی، همان کلید امضا را در محیط امن (مانند Secrets / متغیرهای محیطی CI) نگهداری کنید.

### بیلد خودکار روی GitHub (GitHub Actions)
- فایل `.github/workflows/android-build.yml` در پروژه قرار داده شده است.
- پس از Push به مخزن GitHub (از دکمه **Push to GitHub** در AI Studio)، این Workflow به‌صورت خودکار اجرا شده، فایل `libv2ray.aar` را با بررسی `SHA-256` دریافت می‌کند، تست‌های واحد را اجرا می‌نماید و فایل `app-debug.apk` را در تب **Actions** بخش **Artifacts** (با نام `CloudFrontScanner-debug-apk`) برای دانلود مستقیم آماده می‌کند.

## ۲. استفاده از اسکن (Scan)
1. **به‌روزرسانی رنج‌های رسمی AWS**: در بالای صفحه اسکن، آخرین وضعیت `ip-ranges.json` رسمی آمازون (`syncToken` و `createDate`) نمایش داده می‌شود. این بخش فقط رنج‌های `CLOUDFRONT` با `region=GLOBAL` را برای اسکن اصلی انتخاب می‌کند (رنج‌های `CLOUDFRONT_ORIGIN_FACING` در بخش جداگانه قابل مشاهده هستند).
2. **انتخاب روش ورودی**:
   - **حالت خودکار (Auto)**: انتخاب خانواده IP (`IPv4 + IPv6` با نسبت ۵۰/۵۰، فقط IPv4 یا فقط IPv6) و تعداد نمونه‌گیری (`50`، `100`، `500`، `1000` یا دلخواه).
   - **حالت دستی (Manual)**: وارد کردن IP تکی، چندخطی، CSV یا CIDR (با چسباندن متن یا فایل TXT/CSV). تمام IPهای معتبر دستی اسکن می‌شوند، موارد تکراری حذف و خطوط خراب با شماره خط گزارش می‌شوند.
3. **وارد کردن کانفیگ VLESS (اختیاری برای مرحله ۱، الزامی برای مرحله ۲)**:
   - لینک `vless://...` را Paste کنید، از فایل بخوانید یا با دکمه **اسکن QR** اسکن کنید.
   - خلاصه تنظیمات با **مخفی‌سازی UUID** و وضعیت سازگاری با CloudFront بلافاصله نمایش داده می‌شود.
4. **اجرای مرحله اول و دوم**:
   - دکمه **شروع مرحله اول** غربالگری TCP / TLS / WebSocket را اجرا می‌کند (با دکمه‌های Pause / Resume / Stop / Clear).
   - پس از پایان یا توقف مرحله اول، از کارت **انتخاب IPهای منتخب برای تست تونل** تعداد IPهای ورودی مرحله دوم (`همه`، `50`، `100` یا انتخاب دستی در تب نتایج) را تعیین کرده و **شروع تست واقعی تونل (Xray)** را بزنید.

## ۳. نتایج، لاگ زنده، تاریخچه و خروجی
- **نتایج (Results)**: IPهای `TUNNEL_PASS` به‌صورت مجزا و بر پایه پایداری و میانه زمان تونل رتبه‌بندی می‌شوند. به‌صورت پیش‌فرض ۱۰۰ نتیجه برتر نمایش داده شده و دکمه‌های **۱۰۰ مورد بعدی**، **نمایش همه** و **دلخواه** در پایین فهرست قرار دارند.
- **خروجی و اشتراک‌گذاری**: از گزینه‌های **ذخیره فایل (SAF)** و **اشتراک‌گذاری** برای خروجی TXT، CSV و JSON (با مخفی‌سازی خودکار UUID) استفاده کنید.
